# Brand Admin Schemes 0.16.1

- **Improved:** Adopts the Daily Scripture settings footer with plugin name, version and changelog on the left, plus a documentation link and the slogan “Your colors. Your WordPress.”
- **Improved:** Local documentation dialogs keep the editor draft in place. Links fall back to the localized text readme without JavaScript. The changelog dialog displays only release history.
- **Misc:** Sets the DECKERWEB copyright range to © 2022–2026 in the plugin, bundled updater and all four readmes.

Requires WordPress 6.4+ and PHP 8.0+. Updates come from the DECKERWEB GitHub repository and use the regular WordPress plugin update system. No additional updater plugin is required.
