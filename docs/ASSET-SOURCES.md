# Asset sources

[Deutsch](ASSET-SOURCES-de.md)

The existing BAS SVG icon and EN/DE banner sources were supplied by David Decker in the project handoff. They are original project artwork under the plugin's GPL v2 or later license. Alternative concepts are archived privately outside public distributions. No premium plugin graphics or code were copied for this update. The 1280 × 640 GitHub variants adapt the existing approved banner geometry and text, retaining its palette and admin illustration; they are illustrations, not screenshots. Existing WordPress banner and icon sizes remain unchanged.

SVG text uses the local system Arial/sans-serif fallback; no font files or remote fonts are distributed. PNG artwork is rendered locally from the checked SVG. Library runtime icons are byte-identical to the original 1.1.0 component; provenance is maintained in the original component kit's source records. Verify supplied rights with the maintainer if any new third-party artwork is proposed.



The shared color dialog follows the GPL-2.0-or-later reference implementation 0.0.159 color-control pattern by David Decker – DECKERWEB. WordPress supplies the local ColorPicker/element components; no third-party picker service or remotely loaded runtime is included.
