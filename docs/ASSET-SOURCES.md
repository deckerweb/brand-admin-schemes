# Asset sources

[Deutsch](ASSET-SOURCES-de.md)

The existing BAS SVG icon and EN/DE banner sources were supplied by David Decker in the project handoff. They are original project artwork under the plugin's GPL v2 or later license. Alternate halo/spectrum concepts remain in `assets-github/alternatives/` as design history, outside the installable package. No premium plugin graphics or code were copied for this update. The 1280 × 640 GitHub variants adapt the existing approved banner geometry and text, retaining its palette and admin illustration; they are illustrations, not screenshots. Existing WordPress banner and icon sizes remain unchanged.

SVG text uses the local system Arial/sans-serif fallback; no font files or remote fonts are distributed. PNG artwork is rendered locally from the checked SVG. Library runtime icons are byte-identical to the original 0.5.0 package; provenance is maintained in the original component kit's source records. Verify supplied rights with the maintainer if any new third-party artwork is proposed.

The EN/DE screenshots in assets-github/screenshots are captured from a disposable local WordPress 6.7 demo with official Core translations and the prepared 0.18.0 build. The demo uses manual colors and generated test media; no customer screenshot, private profile, licensed builder UI or mockup is represented. The prepared-release notice in the history screenshot is updated when publication is approved. Screenshots remain in the repository and are excluded from the installable ZIP.
