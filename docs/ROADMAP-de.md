# Roadmap

[English](ROADMAP.md)

Version 1.0.0 enthält den gemeinsamen Farbwähler, gesperrte Markenfarben, Kontrastprüfung, Stand-/Entwurfsvergleich, Schemaverwaltung, Zurücksetzen, portable Vorlagen, begrenzten Verlauf, Schutz paralleler Bearbeitung, Netzwerk-Startvorlagen und optionale Leitstand-Anbindung.

Weitere Prüfungen sind auf lizenzierten Provider-/Builder-Konfigurationen, mit Screenreadern, PHP 8.0 und produktionsnahen MySQL-/MariaDB-Konfigurationen sinnvoll. Weitere Änderungen folgen konkreten Rückmeldungen.
