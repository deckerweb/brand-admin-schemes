# Release policy

[Deutsch](RELEASE-POLICY-de.md)

Feature versions introduce compatible functionality; fix versions correct existing behavior. Incompatible changes require explicit documentation and approval. Version 1.0.0 includes Library 0.6.0 and Updater 2.1.0. Settings, media and personal colors survive updates. Publish only after explicit approval and package validation. Recent history contains seven versions or extends to two feature releases; full history stays in the Wiki.
