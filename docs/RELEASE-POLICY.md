# Release policy

[Deutsch](RELEASE-POLICY-de.md)

Feature versions introduce compatible functionality; fix versions correct existing behavior. Incompatible changes require explicit documentation and approval. Version 1.2.0-rc3 includes Library 1.3.0 and Updater 2.4.0. Settings, media and personal colors survive updates. Publish only after explicit approval and package validation. Recent history contains seven versions or extends to two feature releases; full history stays in the Wiki.
