# Roadmap

[Deutsch](ROADMAP-de.md)

0.18.0 combines the implemented optional setup and eight-field informational Site Health section with per-site Multisite branding, profile/AJAX/Undo adapters, contextual icons and original Library 0.5.0. These are implemented local test features, not published promises. Never reapply the old standalone Site Health patch.

Next: complete actual WordPress/browser/provider/media acceptance and prepare stable 0.18.0 after explicit release authorization. Concrete Leitstand integration must use its real interfaces; no network-wide branding distribution is promised. Existing contrast/source-drift features remain available. Color locks, richer preview galleries, longer history and agency templates require a separate feature review. Real anonymized screenshots remain a low-priority follow-up.
