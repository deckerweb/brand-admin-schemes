# Plugin profile

[Deutsch](PROFILE-de.md)

Brand Admin Schemes by David Decker – DECKERWEB styles the WordPress admin shell, login, toolbar and browser tabs for site owners and agencies. Existing product name and slug: `brand-admin-schemes`; no series rename. Distribution: public GitHub direct download with Updater V2; this build is not a WordPress.org package. Copyright © 2022–2026, GPL v2 or later. Current release: 1.0.0.

Existing minimums remain WordPress 6.4 and PHP 8.0. The embedded original Library 0.6.0 has the same minimums. No platform increase or new design exception has been approved. Manual palettes work independently; Core Framework, Bricks and ACSS are optional and read through guarded adapters. Saved colors remain available if a provider disappears. SVG login media requires Safe SVG and explicit confirmation; agency bundles need ZipArchive; PNG media writes need a supported WordPress image editor.

Individual-site and network activation are supported; settings, login media and Site Icons belong to each site. Personal choices are per-site in Multisite, global in network admin. Library settings are network-scoped. BAS works without Leitstand; its future adapter must use actual documented interfaces. `bas_site_settings_changed` reports only site ID and operation.

Assets and documentation remain local. [Data](DATA.md), [security](../SECURITY.md), [language glossary](GLOSSARY.md), [release policy](RELEASE-POLICY.md) and [testing](TESTING-1.0.0.md) document behavior. Screenshots remain an optional transition task and do not replace runtime tests.
